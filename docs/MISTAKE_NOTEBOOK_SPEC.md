# Mistake notebook

## Purpose
Capture incorrect and unanswered practice items so learners can revisit the concept, compare their response with the correct answer and read the explanation.

## Current scope
- Biology quick practice saves an item when the learner selects an incorrect answer.
- Timed Biology CBT saves incorrect and unanswered items when the mock is submitted.
- Each entry stores the question ID, syllabus topic ID, question, learner response, correct response, explanation and timestamp.
- Entries are stored locally on the device and remain available offline.
- Learners can mark an item as reviewed or return it to the review list.

## Academic safeguards
- Saved explanations inherit the question-bank status. The current Biology bank is original and unverified pending independent subject review.
- A mistake record is a learning aid, not a diagnosis of ability or an official examination result.
- Marking an item reviewed records that the learner has revisited it; it does not demonstrate mastery.

## Next improvements
